# Quick Setup Guide

## 🚀 Get Started in 5 Minutes

### 1. Install Dependencies
```bash
npm install
```

### 5. Start Server
```bash
npm run dev
```

Server will be running at: `http://localhost:5000`

## 📍 Quick Test

Test the API:
```bash
curl http://localhost:5000/health
```

## 📚 Full Documentation

See [README.md](./README.md) for complete API documentation.

## 🔑 API Endpoints Summary

- **Auth**: `/api/auth` - signup, login, profile
- **Teams**: `/api/teams` - CRUD operations
- **News**: `/api/news` - articles management
- **Jobs**: `/api/jobs` - career postings
- **Products**: `/api/products` - store items
- **Players**: `/api/players` - player profiles
- **Matches**: `/api/matches` - match history
- **Sponsors**: `/api/sponsors` - sponsor management
- **Management**: `/api/management` - leadership team

## 🛠️ NPM Scripts

- `npm start` - Start production server
- `npm run dev` - Start development server with auto-reload
